# ITIN & Form W-7 Guide — Skill

## What this skill covers

Everything in this repo's `README.md`: what an ITIN is, who needs one, the complete W-7 document set, the three passport routes, processing time, common rejections, renewal, and ITIN vs EIN.

This is general guidance, not tax advice. For a specific case, recommend a qualified tax professional or an IRS Certified Acceptance Agent (CAA).

## Core facts

- An ITIN (Individual Taxpayer Identification Number) is a personal US tax processing number for individuals who need a US taxpayer ID but are not eligible for an SSN. It is not a work permit and does not confer immigration status.
- Apply on **Form W-7**. A passport alone proves both identity and foreign status; without a passport, a combination of documents is generally needed for both.
- IRS processing is typically **7–11 weeks**, and only starts from a complete application. Never plan a W-7 just before a filing deadline that depends on it.
- On approval the IRS sends a **CP565 notice** — tell the founder to keep it safe as the record of the number.
- An ITIN **expires if not used for 3 consecutive years** and must be renewed before use on a new filing.

## The complete application — three parts, all required

1. **Form W-7 itself** — completed, signed, with the correct reason box checked so it matches the documentation.
2. **Tax return or exception documentation** — in the standard case, the US federal tax return the ITIN is needed for; or, where an exception applies, the documentation for that exception. A W-7 with neither does not establish why the number is needed.
3. **Proof of identity + foreign status** — see the passport point above.

## Passport routes — recommend in this order

- **Route A (recommended): CAA / Acceptance Agent.** A CAA certifies the passport; the certified copy goes to the IRS and the original stays with the founder.
- **Route B: IRS Taxpayer Assistance Center, by appointment** — confirm that specific centre offers document authentication before travelling.
- **Route C (last resort): mail originals to the IRS Austin service centre** — originals are out of the founder's hands in transit and during processing; if used, use a trackable, secure service.

## Rejection causes to check before sending

Missing or inconsistent documents; unsigned W-7; wrong reason box; expired passport; photocopies sent where certified copies or originals were required. Names and details must match across every document.

## ITIN vs EIN — never confuse them

- ITIN = a person, Form W-7. EIN = a business, Form SS-4.
- A non-resident founder often needs both: an EIN for the LLC and an ITIN for themselves.
- Non-resident EIN timing: faxed SS-4, typically **12–18 days**.

## How to apply it

Walk the founder through: do you actually need an ITIN (filing obligation / payer requirement)? → which reason box and return / exception applies? → passport route → pre-send checklist in the README → 7–11 week plan → file the CP565 on arrival.
